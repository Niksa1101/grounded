# 3.06 — Citation validation, mapping and marker rewriting

> **Before you start:** read [AGENTS.md](../../AGENTS.md), the rules in [tickets/README.md](../README.md) (how to work a ticket, ticket types, [standard checks](../README.md#standard-checks)) and the phase notes in [README.md](README.md). Work only on this ticket.

> **Owner:** G · **Type:** Build · **Branch:** `phase-3/citations` · **Blocked by:** 3.05 ·
> **Builds on:** 3.04 label map, 3.05 pipeline

**What to build:** the server turns model labels into trustworthy citations. Invalid labels are removed **and
counted**, `[cK]` markers become display numbers `[n]`, and each cited chunk becomes one `Citation` with a DB-sourced URL.

**Read first:** Tech §9.5 step 2 (semantic checks), Tech §9.6 (mapping rules), PRD FR-10, AGENTS.md §6.3.

**Scope notes**
- `generation/citations.py`, pure where possible.
- Valid label = present in this request's label map. Invalid ones are removed from claims **and** from
  `answer_markdown`, and counted into `invalid_citation_count` (kept for logs and eval, never silently fixed).
- Display numbering: order of first appearance in `answer_markdown`. Claims map to the same `n`. Citations are ordered
  by `n`.
- `Citation.title` is the page H1, which `RetrievedChunk` doesn't carry. Fetch titles for the cited chunk ids with a
  small query (chunks → documents) instead of changing the Author's hybrid SQL.
- `snippet` = the first ~300 characters of the chunk content (cut on a word boundary; document the rule).
- Semantic checks (they return a "bad output" signal consumed by 3.07): `answered|partial` with **zero valid citations**
  → bad output; `insufficient_context` with claims → claims dropped and counted.
- Edge cases to test: repeated markers, adjacent markers `[c1][c2]`, a marker for a label not in any claim, a marker
  inside a fenced code block (decide: leave code untouched), a label cited only in claims but not in the text.

**Acceptance criteria**
- [ ] Unit tests for every rule and edge case above. The pipeline uses the module, and `AskResponse.citations` has
      real URLs with anchors.
- [ ] `invalid_citation_count` is available to the pipeline (logged in 3.12).

**Verify:** standard checks.

**Eval impact:** none measurable yet.
