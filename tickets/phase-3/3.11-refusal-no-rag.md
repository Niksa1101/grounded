> **Before you start:** read [AGENTS.md](../../AGENTS.md), the rules in [tickets/README.md](../README.md) (how to work a ticket, ticket types, [standard checks](../README.md#standard-checks)) and the phase notes in [README.md](README.md). Work only on this ticket.

> **Owner:** G · **Type:** Build · **Branch:** `phase-3/refusal-no-rag` · **Blocked by:** 3.10

**What to build:** out-of-corpus questions end as a clean `insufficient_context` answer, and the pipeline gets a
`no_rag` mode (same schema, no sources) for the Phase 4 baseline.

**Read first:** Tech §9.7 (refusal rules; no score-threshold short-circuit in MVP), Tech §7 (modes), Tech §15.3
(`no_rag` config), PRD FR-11, UC4.

**Scope notes**
- Refusal: no claims, no citations; `follow_up_questions` allowed. The UI state comes later.
- `no_rag`: skips embedding and retrieval, and uses a sibling prompt without sources (`answer_no_rag_v1.md`, same
  family and schema; the Author approves the wording). The **zero-valid-citations check is disabled** in `no_rag`
  (otherwise every answer would retry). Confidence for `no_rag` claims: they have no citation, so the ≤ 0.2 cap applies.
- `no_rag` isn't exposed on the public HTTP API (eval and CLI only): `grounded ask --mode no_rag`.

**Acceptance criteria**
- [x] Fake-provider tests: the refusal path end to end; `insufficient_context` with claims → dropped and counted;
      `no_rag` makes zero embedding/DB retrieval calls and never retries for missing citations.
- [ ] The `no_rag` prompt is approved by the Author. _Pending Author review: `backend/prompts/answer_no_rag_v1.md` was written by the agent under delegation (PR #50)._

**Verify:** standard checks, then `uv run grounded ask --mode no_rag "…"` (fake, or real by the Author).

**Stop and ask:** the new prompt wording.

**Eval impact:** none measurable yet.
