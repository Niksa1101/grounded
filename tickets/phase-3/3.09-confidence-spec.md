**Scope notes**
- `generation/confidence.py`: `score_claims(claims, label_map, retrieved, *, config) -> list[ClaimScore]`, with `ClaimScore`
  frozen (`confidence`, `components: dict[str, float]`), a contract docstring and `NotImplementedError`. `config` is a
  frozen `ConfidenceConfig` (the weights and the uncited cap, `ConfidenceConfig.from_settings(settings)`), so the function
  stays pure and reads no settings itself. The component keys are the constant `COMPONENT_KEYS`.
- Weights as `Settings` fields (propose names, e.g. `CONFIDENCE_W_*`, and a cap for uncited claims), in
  `.env.example`. The Author may rename them.
- Invariant tests (table-driven, deterministic):
  - `confidence ∈ [0, 1]` for all inputs.
  - A claim with **no valid citation → ≤ 0.2**.
  - `self_confidence = 1.0` with the weakest possible retrieval support → **≤ 0.6**.
  - **Monotonic:** better retrieval support for a cited chunk (a better rank, dense/FTS agreement, more valid
    citations) never lowers confidence.
  - `rerank_score = None` (rerank off) is handled. Rerank present (Phase 6) may add support.
  - Same input → same output. The component keys are listed in the docstring.
- `xfail(strict=True, reason="Author implements in 3.10")`.
