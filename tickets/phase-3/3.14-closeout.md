## Closeout report

**Phase 3 is closed.** Every exit criterion passes. The real-provider golden-set run was done on 2026-10-07
(`gemini-3.5-flash-lite`, thinking level `minimal`, prompt `answer_v1@08cc49e5`, index `0.141.1@4949e8a3`,
golden set v1, hybrid mode, `APP_ENV=eval` so the answer cache was off), at the Author's request, using the key already
in the Author's `.env`. Output of `grounded ask --golden ../eval/golden/golden_set.v1.jsonl`:

```
Golden set v1: 30 questions, hybrid mode
Questions: 30/30 run
Status: answered 23, insufficient_context 7
Schema-valid AskResponse: 30/30
Validation retries: 0; invalid citations removed: 0; claims dropped: 0
Cache hits: 0; rate-limit waits: 1
Shadow cost: $0.047498 (successful attempts only)
```

Per-request latency (`meta.latency_ms.total`): min 1286 ms, median 1887 ms, max 2631 ms. A 2-question trial run
came first (2/2 valid). The results file is `eval/results/20261007T094211Z-ask.json` (gitignored).

**Findings for Phase 4 (informational, not a gate):**
- The 7 `insufficient_context` answers are q016, q026 and the five unanswerable questions (q045, q047, q049, q050,
  q051). **q016 and q026 are `answerable: true` in the golden set, so those two are false refusals** (2 of 25
  answerable questions). The prompt was not tuned against this (AGENTS.md §13); Phase 4 measures it.
- The one rate-limit wait: the free tier allows 15 requests a minute for this model and the batch hit it once; the tool
  waited the advertised `Retry-After` and went on.
- `answer_no_rag_v1` on real Gemini (one answerable and one unanswerable question): both answered, with no citations and
  every claim at confidence 0.15 (under the 0.2 uncited cap). The unanswerable question (q045's text) was **answered,
  not refused**, so the no-RAG baseline does not refuse out-of-corpus questions, which is the contrast Phase 4 wants.
