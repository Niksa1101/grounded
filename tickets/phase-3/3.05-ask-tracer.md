> **Owner:** G · **Type:** Build · **Branch:** `phase-3/ask-tracer` · **Blocked by:** 3.04 ·
> **Builds on:** 2.06 `hybrid_search`, `retrieval/index.py`, `ingest/embed.py`, 3.02–3.04, `main.py` lifespan, `api/deps.py`

**What to build:** a thin but complete path: an HTTP request → validation → query embedding → hybrid retrieval →
context → generation (fake in tests) → basic citation mapping → a validated `AskResponse`. Later tickets thicken each
stage.

**Read first:** Tech §6 (request path and sequence diagram), Tech §9.4 (`AskRequest`, `AskResponse`, `Citation`, `Claim`,
`Meta`), Tech §13 (error shape and codes), Tech §11 (query-embedding cache), DB §7.3 (active index cached, refreshed
every 5 min), Tech §18 (lifespan duties).

**Scope notes**
- `schemas/api.py` with the Tech §9.4 models. `api/errors.py` with the shared error shape
  `{error: {code, message, retry_after_s}, request_id}` and exception handlers (422 → `bad_request`).
- `generation/pipeline.py` orchestrates the stages. `api/routes_ask.py` is thin.
- Lifespan: the embedder and provider are created once. The active index version is cached with a 5-minute refresh.
  **`/readyz` now requires an active index** (Tech §13 says it becomes required in Phase 3).
- Query embedding with `RETRIEVAL_QUERY`: an in-memory LRU in prod, SQLite in dev/eval (Tech §11).
- Dependency injection lets tests swap in the fake provider and a fake embedder (via the app factory or dependency
  overrides). No real calls.
- **Allowed placeholders** (each filled later in this phase, listed in the PR): per-claim `confidence = 0.0` with empty
  components (never `self_confidence`, AGENTS.md §6.6) until 3.10; `shadow_cost_usd = 0.0` and partial `latency_ms`
  until 3.12. Nothing else may be stubbed.
- A `grounded ask "<question>"` CLI command for local runs (Tech §3 lists `ask`). It prints the `AskResponse` JSON.
- The route is unprotected in dev until 5.03 (proxy secret). Note it in the PR.

**Acceptance criteria**
- [ ] Service test via `httpx.AsyncClient(app)` with `FakeLLMProvider`, a fake embedder and the real DB fixture index →
      200 and a schema-valid `AskResponse`.
- [ ] Error-shape tests: 422 `bad_request` for a too-short or too-long question, 500 `internal_error` with a
      `request_id`, no stack trace in the body.
- [ ] `/readyz` fails without an active index (test).
- [ ] `grounded ask` works locally with the fake provider (a `--fake` flag, or settings selecting it in dev).

**Verify:** standard checks, then `uv run grounded serve --reload --port 8000` and one `curl` against `/v1/ask`
(output in the PR).

**Stop and ask:** any field change vs Tech §9.4 or §13.

**Eval impact:** none yet.
