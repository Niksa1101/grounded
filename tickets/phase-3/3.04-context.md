**Scope notes**
- `generation/context.py`, pure. The attributes `section` (breadcrumb text) and `url` come from DB fields. The LLM
  never sees DB ids.
- **Document order of adjacent parts:** `RetrievedChunk` has no `ordinal`. Don't assume that chunk-id order equals
  document order without checking how ingest inserts (it may hold today, but that isn't a contract). If `ordinal` is
  needed in `RetrievedChunk`, it touches the Author's hybrid SQL → **ask the Author**.
- **Injection-safe blocks:** chunk content containing a literal `</source>` or `<source` must not break the framing.
  Choose an escaping rule, document it, and test it.
- Deterministic output for the same input (the eval LLM cache in 4.03 is keyed by the full prompt).
