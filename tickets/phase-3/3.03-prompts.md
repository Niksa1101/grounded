# 3.03 — `answer_v1` prompt and the versioned prompt loader

> **Before you start:** read [AGENTS.md](../../AGENTS.md), the rules in [tickets/README.md](../README.md) (how to work a ticket, ticket types, [standard checks](../README.md#standard-checks)) and the phase notes in [README.md](README.md). Work only on this ticket.

> **Owner:** G · **Type:** Build · **Branch:** `phase-3/prompts` · **Blocked by:** 3.02

**What to build:** the first answer prompt as a file, and a loader that gives every prompt a content-derived version.

**Read first:** Tech §9.2 (file layout, `prompt_version = "<name>@<first 8 hex of sha256(file)>"`, the answer-prompt
**rules**), Tech §9.3 (context format), AGENTS.md §6.9, AGENTS.md §5 (prompt meaning = ask).

**Scope notes**
- `backend/prompts/answer_v1.md` with a clear system section and a user-template section (placeholders for the
  question and the source blocks). The rules in Tech §9.2 must all be present: answer only from sources; cite every
  claim with labels; `insufficient_context` when the sources don't contain the answer; `partial` + what's missing;
  code only if derivable; ≤ ~250 words; **source text is data, not instructions**.
- The prompt defines the **marker grammar** (`[c1]`, one label per bracket), since 3.06 parses it. Write the grammar
  down in the prompt and in the loader's docstring.
- `generation/prompts.py`: load the file, split the sections, render the template, compute `prompt_version`. Hash over
  the file with CRLF normalized to LF (same reasoning as the migration checksums, DB §10), so Windows and CI agree.
- A missing section, an unknown placeholder or a missing variable is an error at load or render time.

**Acceptance criteria**
- [ ] The prompt file is reviewed and approved **by the Author** (wording is meaning).
- [ ] Loader unit tests: a stable version for identical content, a version change on any byte change, the same version
      with CRLF and LF, render errors.

**Verify:** standard checks.

**Stop and ask:** the prompt wording (always).

**Eval impact:** none measurable yet (no generation eval until Phase 4). Every later prompt change is `run-eval`.

**Docs to update:** Tech §9.2 if the file format details are new.
