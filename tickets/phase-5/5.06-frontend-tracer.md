# 5.06 — Tracer bullet: frontend proxy, generated types, minimal ask page

> **Before you start:** read [AGENTS.md](../../AGENTS.md), the rules in [tickets/README.md](../README.md) (how to work a ticket, ticket types, [standard checks](../README.md#standard-checks)) and the phase notes in [README.md](README.md). Work only on this ticket.

> **Owner:** G · **Type:** Build · **Branch:** `phase-5/frontend-tracer` · **Blocked by:** 5.05 ·
> **Builds on:** `frontend/` scaffold (Next.js App Router, Tailwind, shadcn/ui), 5.03 security, 5.02 timeouts

**What to build:** a question typed in the browser goes through the Next.js Route Handler to the backend and renders
the answer. The TypeScript types are generated from the backend's OpenAPI schema.

**Read first:** Tech §18 "Frontend — Vercel" (env, Route Handlers, `maxDuration`), Tech §19 (types generated with
`openapi-typescript`), Tech §12 (output rendering: no raw HTML), AGENTS.md §6.14, §9 TypeScript.

**Scope notes**
- `app/api/ask/route.ts`: server-only. It forwards to `BACKEND_URL/v1/ask` with `X-Proxy-Secret` and `X-Client-IP`
  (from the platform's forwarded-for header; verify which header Vercel sets and take the right hop), with the timeout
  and `export const maxDuration` from 5.02. **No `NEXT_PUBLIC_` secrets.**
- OpenAPI → types: a backend command that dumps the OpenAPI JSON (e.g. `grounded openapi --out …`), and an npm script
  running `openapi-typescript` into `frontend/lib/`. Decide whether the generated file is committed (probably yes, with
  a CI check that it is current).
- A minimal page: an accessible form (label, submit) and the answer Markdown rendered with `react-markdown` without
  raw HTML. Links open with `rel="noopener noreferrer"`.
- `openapi-typescript`, `react-markdown` and `remark-gfm` are new npm dependencies (listed in Tech §2, but still new)
  → **ask the Author** first.

**Acceptance criteria**
- [ ] Locally: `grounded serve` + `npm run dev` → a question returns an answer in the browser via `/api/ask`.
- [ ] The types come from generation, and a type mismatch fails `npm run typecheck`.
- [ ] Frontend checks green. A Route Handler unit test (header forwarding, timeout → error JSON) if the test setup
      allows it; otherwise, why not.

**Verify:** frontend standard checks, plus a manual browser run (screenshot in the PR).

**Stop and ask:** the dependencies.

**Eval impact:** none.
