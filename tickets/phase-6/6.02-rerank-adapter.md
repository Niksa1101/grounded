**Scope notes**
- `retrieval/rerank.py` over the SDK's `AsyncClientV2`. It sets `rerank_score` on the returned chunks. Deterministic
  tie-breaking (score DESC, then the original RRF order).
- **The dependency is approved (6.01):** add `cohere==7.2.0` to `backend/pyproject.toml` and `uv.lock` here (13 new
  distributions, +27 MB installed, no existing package changes version; checked in 6.01 on a scratch copy of the lock).
  Import the SDK inside the function that builds the adapter, so a deployment with `RERANK_PROVIDER=none` pays nothing
  (touching `AsyncClientV2` costs about 0.65 s).
- **Build the client as Tech §8 says:** `AsyncClientV2(api_key=…, base_url="https://api.cohere.com",
  timeout=RERANK_TIMEOUT_S, max_retries=0)` and an `asyncio.timeout(RERANK_TIMEOUT_S)` around the call (the SDK retries
  twice with `asyncio.sleep` by default, and it reads `CO_API_KEY` / `CO_API_URL` itself, so both values are passed
  explicitly). Send all candidates and **no `top_n`**; slice to `top_n` in our code. Validate the response with Pydantic
  (one result per document, unique in-range `index`, `relevance_score` in `[0, 1]`) and raise `ProviderBadOutput`
  otherwise. Map the errors exactly as Tech §8 lists them.
- **New `Settings` field `RERANK_TIMEOUT_S`** (default `3.0`, `gt=0`) with its `.env.example` line (the sync test checks
  it); `RERANK_PROVIDER=cohere` without `RERANK_MODEL` or without `COHERE_API_KEY` is an error at startup. Change the
  "planned" in Tech §4 to the real field in this PR. *As built:* like Gemini's key and model, `Settings` does not check
  the pair; `runtime.build_reranker(settings, stack)` raises `ProviderConfigError` naming the variable, returns `None` for
  `RERANK_PROVIDER=none`, and is the factory 6.03 calls from `open_runtime` (nothing calls it before that).
- `.cache/rerank.sqlite` is used in dev/eval only (manual runs; no CI job uses it, 6.01). In prod, the answer cache
  covers repeats. The key is `sha256(model | query | ordered candidate content_hashes)`, with no `top_n`, plus a constant
  that versions how the document text (breadcrumb and content) is built, since the content hashes do not cover it.
- Fixtures are JSON built from the response shape in Cohere's API reference. 6.01 made no real call (no key in `.env`),
  so say in the fixture file that it follows the documented shape and is **not recorded**; a recorded one replaces it
  only after a real call. A fake reranker for tests. Tests never reach Cohere (the socket-blocking fixture stays).
