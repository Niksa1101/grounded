**What to build:** the Author implements the router and breaker so every scenario passes.

**Agent's role:** hints on request (state machine first, then concurrency), then a review: concurrent half-open
(`asyncio.Lock` usage without holding it across provider calls), no leaking open states, time arithmetic on the
injected clock, typed errors only.

**From 7.02:** the contract is the module docstring of `generation/router.py`; the scenarios are
`tests/unit/test_router.py` (remove the `SPEC` marker as each test passes). The pure parts come first and have
tests of their own: `CircuitBreaker`, `quota_reset_s`, `open_plan`; then `ProviderRouter.generate`. Things the
review looks at: no `await` between a breaker's decision and its state change; a half-open trial is resolved on
every path (a hook error, a cancellation, a rejected request and a deadline refusal release it); the breaker is
told of a reply before `validate` and `on_attempt` run; the deadline gate does not consume the trial. The
`BreakerConfig` validation is already in the stub.

**Authorization (AGENTS.md §3).** The Author said "write it" for `generation/router.py` on 2026-10-14, so the Agent
wrote the implementation. The mandatory line-by-line explanation is in the PR description. The Agent also added
`tests/unit/test_router_robustness.py` (cancellation at the other `await`s, hooks that raise, the time boundaries,
the daylight-saving arithmetic from an already-local `now`, seeded random traffic with an audit of every trial and
a recoverability check). The review round of PR #126 added `AllProvidersUnavailable.causes`, `ProviderRouter(...,
breakers_enabled=False)` for eval mode, a narrower `retry_after_s`, `generate(..., log_extra=...)` and a log line per
failed call, with `tests/unit/test_router_review.py`. No 7.02 assertion was changed: the `xfail` markers were
removed, and `test_the_router_never_sleeps...` also poisons `time.sleep` now.
