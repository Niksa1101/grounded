> **Owner:** G · **Type:** Build + Closeout · **Branch:** `phase-7/router-wiring` · **Blocked by:** 7.03

**What to build:** `/v1/ask` generates through the router over `GENERATOR_PROVIDERS`. The single-provider retry from
3.07 moves into the router. Fallback shows up in `meta` and `request_logs`, and the phase closes with a demonstration.

**Read first:** Tech §10, Tech §13 (503 `provider_unavailable` + `Retry-After`), DB §4 (`fallback_used`, `provider`,
`model`, `validation_retries`), PRD FR-15.

**Scope notes**
- Remove the pipeline-level retry (no double retry). The 3.07 tests move or adapt so the behavior stays covered.
- Each fallback call also reserves budget (5.05).
- **From 7.01 (PRD D57):**
  - **A fallback answer is not stored in the answer cache** (`fallback_used` true → no write; the key and the schema do
    not change). Test: a fallback answer leaves no row, a primary answer does, and a cached answer is still served while
    the primary's breaker is open.
  - **An unbuildable fallback is skipped** at startup with a logged WARNING that names the missing variable
    (`GROQ_API_KEY`, `GROQ_MODEL`); startup fails only when the first entry cannot be built. Eval mode is unchanged.
  - **The Gemini client makes one attempt**, set explicitly (`google-genai` 2.25.0 retries nothing by default, but
    Google's docs say its SDKs retry a 429 or 5xx up to four times, which would sleep in the request path and hide a 429
    from the router). A test pins it.
  - **First entry other than `gemini` or `fake`:** outside eval mode it is refused at startup, or the adapter parameters
    (`thinking_level`, `GROQ_REASONING_EFFORT`) move into the providers and the cache key (PRD §12). Ask the Author which.
- `AllProvidersUnavailable` → 503 with `Retry-After`, outcome `provider_unavailable`.
- Eval mode stays primary-only (a startup check from 4.03).
- **Demo:** a service test and a documented local run with a fake Gemini returning 429 → Groq answers, the next request
  skips Gemini while the breaker is open, and the logs show `fallback_used=true`.
- Closeout: exit criteria, README "resilience" note, roadmap, PRD status.
